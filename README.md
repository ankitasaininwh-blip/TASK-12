# TASK-12
Compound Interest Calculator

Description

This project is a simple JavaScript program that calculates compound interest using predefined values.

Formula

A = P × (1 + r/n)^(n×t)

Where:

- P = Principal amount
- r = Rate of interest
- n = Number of times interest is compounded per year
- t = Time in years
- A = Final amount

Compound Interest = A - P

Predefined Values

- Principal = ₹100000
- Rate = 5%
- Compounded = 4 times per year
- Time = 2 years

Output

Compound Interest after 2 years: ₹10,448.61

The calculated values are also displayed in the browser console using "console.log()".
